# Что проверено

## Native CONNECT

- 91 Python-тест и два Node-теста плагинов; общее покрытие 93.84%.
- Установленный сервис на OpenCode 2.1.2 получил `OK` на DeepSeek и MiMo.
- Каждый из трёх локально настроенных аккаунтов получил `OK` через новый SOCKS5h
  с новым плагином. Настоящие ключи не используются в автоматических тестах.
- Проверены CONNECT-авторизация, ограничение назначения `opencode.ai:443`,
  передача непрозрачных байтов, SOCKS5 DNS и отказы протокола.
- Проверены переключение ключей/маршрутов на 429, удаление старой организации,
  пропуск остальных провайдеров и адресов, транспортные ошибки и отмена.
- Настоящая установка native-режима с venv/pip, пути с пробелами, запуск,
  doctor и удаление проверены в отдельной домашней папке.

Прежний HTTP-relay при настоящих запросах получал `FreeUsageLimitError`,
хотя те же ключи работали в нативном клиенте. Точная причина различия
транспортов не установлена. Native-режим сохраняет TLS встроенного клиента.
Дальнейшие результаты относятся к прежнему HTTP-relay.

Локально на Linux с Python 3.12:

- Общее покрытие с ветвлениями: 95.29%.
- Gateway и чтение конфигурации: 100%. Установщик: 93%.

- Проверены переключение на 429, паузы, отказ всех маршрутов и сетевые ошибки.
- Проверены сохранение заголовков, локальный ключ и закрытие потока при ошибке.
- Проверены установка, обновление, удаление, откат и сохранение чужих файлов.
- Настоящая установка с venv и pip прошла в отдельной домашней папке с пробелами.
- Gateway запускался, doctor и удаление отработали. Рабочие файлы машины не менялись.
- Новый gateway и сгенерированный плагин проверены через настоящий opencode run: ответ OK.
