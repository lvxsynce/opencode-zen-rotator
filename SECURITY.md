# Не публикуйте свои ключи

В репозитории должны быть только исходники и примеры с выдуманными данными.

Нельзя добавлять:
- Файл с настоящими прокси и паролями.
- `opencode.json`, `auth.json`, GitHub PAT, SSH-ключи.
- Логи OpenCode, историю чатов и резервные копии ваших настроек.
- Сгенерированный локальный плагин: в нём есть ключ доступа к gateway.

Перед коммитом запустите `python3 scripts/check_secrets.py`. Это дополнительная
проверка, а не гарантия. Всегда смотрите `git diff --cached` сами.
Если ключ уже попал в Git или чат, отзовите его. Простого удаления файла мало.

Gateway не подменяет ключ Zen: он сохраняет заголовки настоящего клиента.
Локальный ключ удаляется перед отправкой запроса в Zen. В журнал пишутся
только номер маршрута и HTTP-статус. Исключения от прокси не выводятся целиком.

Используйте сервис только на своей машине. Не выставляйте порт наружу.
Другие пользователи с root-доступом всё равно могут прочитать ваши файлы.
Установка с root не изолирует код плагина или Python от остальных root-процессов.

GitHub Actions запускает тесты без реальных ключей. Для публикации с вашей
машины используйте авторизацию GitHub CLI. Не добавляйте PAT в URL репозитория,
аргументы команды или файлы проекта.
