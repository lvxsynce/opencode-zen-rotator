# OpenCode Zen Rotator

Теперь запрос в Zen отправляет сам OpenCode через прозрачный HTTPS-туннель.
Старый HTTP-relay может получать ложный `FreeUsageLimitError` и оставлен
только для совместимости. Проверено на OpenCode 2.1.2.

Установщик также спросит ключи твоих аккаунтов Zen. Ввод скрыт; ключи и
прокси хранятся только локально в файле с правами `600`. При `429` пробуется
следующая доступная пара ключа и маршрута. После начала ответа повторов нет.
Внешние провайдеры и нестандартные адреса плагин пропускает напрямую.

Сервис использует два локальных порта: выбранный порт управления и следующий
за ним для CONNECT-туннеля. Не открывай их в интернет.

Маленькая штука для бесплатных моделей OpenCode Zen. Когда появляется
`429 Rate limit exceeded`, пробует тот же запрос через другой адрес.

Можно добавить прямой выход с машины и свои прокси. Обычный `opencode`
остаётся обычным: другие провайдеры и адреса идут напрямую, минуя ротацию.

Это не безлимит. Если лимит есть на всех адресах — придётся подождать.
Используй только свои маршруты и соблюдай правила Zen.

## Нужно

- Linux
- Python 3.10+ с `pip` и `venv`
- Установленный OpenCode. Проверено на 2.1.0
- Свои прокси, если одного прямого подключения мало

## Ставим

```bash
git clone https://github.com/lvxsynce/opencode-zen-rotator.git
cd opencode-zen-rotator
python3 install.py
```

Установщик сам спросит:

- добавить ли прямое подключение и какие прокси использовать;
- какой порт взять;
- установить ли сервис для автозапуска;
- добавить ли алиас, чтобы запускать просто `opencode`;
- проверить ли всё через `opencode run`.

Пароли вводятся скрыто. Настоящие настройки остаются на твоей машине.
Если не найдёт OpenCode, можно подсказать путь:

```bash
python3 install.py --opencode /путь/к/opencode
```

Уже существующие чужие файлы установщик не затирает. Перед изменениями
сохраняет копии. Основной `opencode.json` не меняет.

## Запускаем

Если добавил алиас — открой новый терминал и пиши как раньше:

```bash
opencode
```

Без алиаса: `~/.local/bin/opencode-zen`.
Выбирай встроенные модели `opencode/...-free`, например
`opencode/deepseek-v4.1-flash-free`, если она сейчас есть в каталоге.

Проверить одним запросом:

```bash
~/.local/bin/opencode-zen run   --model opencode/deepseek-v4.1-flash-free   'Reply only with OK.'
```

## Как это работает

```text
OpenCode (нативный HTTPS) → локальный CONNECT → напрямую или SOCKS5h → Zen
```

Пока адрес работает — используется он. При `429` адрес ставится на паузу,
а запрос пробуется через следующий. Если все адреса на паузе, вернётся
ошибка с временем ожидания. Бесконечных повторов нет.

Уже начавшийся ответ не перезапускается. Лимит внутри потока с кодом `200`
пока не обрабатывается. Системные маршруты и SSH не меняются.

## Сколько раз переключался

```bash
curl -s http://127.0.0.1:18998/health
```

`rotations_429` — переключения из-за HTTP `429`. `rate_limits_429` — всего
полученных ответов `429`. `successes` — успешные запросы, `active_tunnels` —
открытые туннели. Ключи и адреса в статистику не попадают. Счётчики
обнуляются при перезапуске. Если выбрал другой порт, замени `18998`.

## Если не работает

```bash
python3 install.py doctor
journalctl --user -u zen-rate-gateway -n 30 --no-pager
```

Если ставил от root, убери `--user`. Если порт занят — выбери другой.
На Debian/Ubuntu для создания окружения может понадобиться `python3-venv`.
Если не работает прокси — проверь адрес, логин и пароль.

Подробности, ручной запуск и список файлов — в [инструкции](docs/guide.md).

## Обновляем или удаляем

Сначала получи свежие файлы: `git pull --ff-only`. Затем:

```bash
python3 install.py update
# или
python3 install.py uninstall
```

Не обновляй во время ответов модели. Чужие изменения при удалении
сохраняются; список прокси можно оставить.

## Тесты

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[test]'
.venv/bin/python -m pytest --cov=zen_rotator --cov=install
node tests/test_plugin.mjs
```

Тесты не используют настоящие прокси. Результаты и ограничения —
в [TESTING.md](TESTING.md). GitHub Actions запускает их на Python 3.10–3.12.

## Ключи и пароли

Не коммить свои прокси, токены, логи и настройки OpenCode. Проверка перед
коммитом: `python3 scripts/check_secrets.py`. Она помогает, но не заменяет
проверку файлов глазами. Подробнее — [SECURITY.md](SECURITY.md).
